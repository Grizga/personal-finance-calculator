# API Документация

## Функции модуля main.py

### `load_data()`
Загружает данные из файла data.json.
- **Возвращает:** список операций (словари)

### `save_data(data)`
Сохраняет данные в файл data.json.
- **Параметры:** `data` - список операций

### `add_operation()`
Добавляет новую операцию через интерактивный ввод.

### `show_operations()`
Выводит таблицу всех операций.

### `show_balance()`
Рассчитывает и выводит баланс (доходы - расходы).

### `menu()`
Запускает главное меню приложения.
