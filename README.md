# Калькулятор личных финансов

Консольное приложение на Python для учета доходов и расходов.

## Описание
Простое приложение, которое позволяет пользователю вводить свои доходы и расходы, категоризировать их и просматривать краткую статистику в интерактивном режиме.

## Установка и запуск
Для работы требуется Python 3.8+.

1. Клонируйте репозиторий:
   `git clone https://github.com/Grizga/personal-finance-calculator.git`
2. Перейдите в папку проекта:
   `cd personal-finance-calculator`
3. Запустите приложение:
   `python src/main.py`

## Использование
После запуска появится консольное меню:
- **1** — Добавить новую операцию (доход/расход) с указанием суммы, категории и даты.
- **2** — Просмотреть список всех операций.
- **3** — Вывести текущий баланс (доходы минус расходы).
- **4** — Выход из приложения.
