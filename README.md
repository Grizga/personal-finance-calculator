# Калькулятор личных финансов

![Python](https://img.shields.io/badge/Python-3.6+-blue.svg)

Простое консольное приложение для учёта личных доходов и расходов.

## Описание

Приложение позволяет:
- Добавлять операции (доходы и расходы) с категорией и датой
- Просматривать список всех операций
- Видеть текущий баланс
