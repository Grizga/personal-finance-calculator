# Руководство пользователя

## Запуск
1. Убедитесь, что установлен Python 3.6 или выше.
2. Откройте терминал в папке проекта.
3. Запустите команду: `python src/main.py`

## Использование
- Выберите пункт меню цифрой.
- Для добавления операции укажите тип (доход/расход), сумму, категорию и дату.
- Для просмотра баланса выберите пункт 3.

## Хранение данных
Все операции сохраняются в файл `data.json` в корне проекта.
