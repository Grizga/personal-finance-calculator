# API документация

## Функции модуля main.py

### `load_data()`
Загружает список операций из файла `data.json`.
- **Возвращает:** список словарей с операциями.

### `save_data(data)`
Сохраняет список операций в файл `data.json`.
- **Параметры:** `data` — список словарей.

### `add_operation()`
Добавляет новую операцию через интерактивный ввод.

### `show_operations()`
Выводит таблицу всех операций.

### `show_balance()`
Выводит доходы, расходы и текущий баланс.

### `menu()`
Запускает главное меню приложения.
